
# 科研工作台使用说明

## 打开工作台
- 左侧边栏的 🧪 烧瓶图标，或命令面板（Ctrl+P）搜索「打开科研工作台」
- 默认启动 Obsidian 时自动打开（可在设置里关闭）

## 核心思路：项目 × 流程
每个项目按它的类型走一套流程，比如论文是 **灵感 → 文献综述 → 实验与数据 → 论文写作 → 投稿发表**；类型和流程都可以自己定义（见 v0.22）。
- **首页 · 看板**：每一列是一个阶段，每张卡片是一个项目。把卡片拖到另一列，就推进了项目阶段（会自动写进项目主页的「进展日志」）
- **首页 · 矩阵**：每一行是一个项目，每一列是一个阶段，格子里是该项目在该阶段积累的笔记数；点击格子跳到对应标签页并自动筛选该项目
- **项目页**：所有项目的大卡片，点阶段圆点可直接切换阶段
- **灵感 / 文献 / 实验与数据 / 写作 / 投稿 / 会议**：每类笔记按状态分列（看板）或列成表格；顶部显示当前处于该阶段的项目
- **计划**：自动汇总所有 `- [ ]` 待办和截止日期，勾选会直接修改原笔记
- **AI 助手**：常用的 Claude Code / Codex 指令，一键复制

## 📥 拖入文件（v0.2）
- 从电脑把任意文件（PDF、PPT、Excel、实验数据、录音、图片、代码…）直接拖进工作台任意位置，会弹出导入窗口，按扩展名自动分类，可逐个修改
- **拖到首页 / 项目页的某张项目卡片上** = 直接放进那个项目；在项目详情页或带项目筛选的页面里拖入，也会默认归到当前项目
- 文件按分类存到 `科研/项目/<项目名>/文献|汇报|数据|会议|写作|图片|代码|附件/`
- 「保存方式」可选「只记录链接」：几个 GB 的原始数据不用复制进库，工作台记下原位置，照样能一键打开（默认超过 200 MB 自动切换，可在设置里改）
- 文献 PDF 可自动生成阅读笔记，录音 / 视频可自动生成会议纪要（笔记里内嵌播放器）

## 📂 打开文件
- 「文件」标签页列出所有文件，可按项目、分类筛选
- PDF、图片、音视频在 Obsidian 里打开；PPT、Excel、Word、Origin、数据文件等用电脑上的默认程序打开
- 每行右侧可「在文件夹中显示」；右键可移动到其他项目、改分类、复制路径、为文件创建笔记

## 📁 项目详情页
点击任意项目卡片进入详情页：阶段进度、下一步、按流程分组的全部笔记、按分类分组的全部文件、待办，一页看完。把文件拖进详情页即放进该项目。

## 📚 Zotero 联动
1. 安装并打开 **Zotero 7**，在 Zotero 的 设置 → 高级 中勾选「允许此计算机上的其他应用程序与 Zotero 通讯」
2. 在工作台「文献」页点「从 Zotero 导入」：可按 Zotero 分类浏览、搜索标题 / 作者 / 年份，勾选后导入到指定项目
3. 导入的文献笔记带作者、年份、期刊、DOI、引用键、摘要；卡片上有「Zotero」「PDF」按钮，点击直接跳回 Zotero 打开原文（批注仍保存在 Zotero 里）
4. 在 Zotero 里做了高亮 / 批注后，点「同步批注」，批注会更新到笔记的「Zotero 批注」部分，点页码可跳回 PDF 对应位置

## 🗑 删除（v0.3）
- **笔记 / 文件**：鼠标移到卡片或表格行上，右侧会出现垃圾桶图标；也可以右键 →「删除…」
- **项目**：项目卡片上的垃圾桶、右键菜单，或项目详情页右上角「删除项目」。可选择：
  - 删除整个项目文件夹（项目主页 + 其中全部笔记和文件）
  - 只删除项目主页，笔记和文件保留，变成「未归属项目」
- **链接文件**（只记录链接的大文件）：只删除工作台里的记录，电脑上的原文件不动
- 所有删除都会先弹窗确认，删除的内容进入回收站（系统回收站或 Obsidian 的 .trash，取决于 Obsidian「文件与链接」设置），可找回
- 项目只是结束了的话，建议把状态改成「已完成」来归档，不必删除

## 📝 没有属性的 md 也能识别（v0.4）
- 放在 `科研/` 里、但开头没写 `type` 等属性的 md，会按所在文件夹自动识别：`会议/` → 会议纪要，`文献/` → 文献，`实验/` → 实验……（项目文件夹里的同样适用，并自动归到该项目）
- 文件名只是日期（如 `2026-06-25.md`）时，标题会自动带上笔记里的第一个标题；日期从文件名读取
- 这类笔记会显示橙色「未加属性」标记：点它，或点页面顶部「补全属性（N）」，即可把 type / status / date 写进文件开头（正文不动）
- 识别错了类型？右键 →「改为 → 写作 / 文献 …」
- 放不进任何分类文件夹的 md（比如 `附件/` 里的）会出现在「文件」页，右键 →「转为笔记 → …」
- 从电脑拖入 .md 文件时，会直接作为笔记导入（不再当附件）：在某个笔记页拖入就用该类型，文件名像日期的默认为会议纪要，导入窗口里可逐个修改

## 🗂 项目类型（v0.5）
新建项目时先选类型，每种类型有自己的流程：
| 类型 | 适合 | 流程 |
|---|---|---|
| 论文 | 以写出、发表一篇论文为目标 | 灵感 → 文献综述 → 实验与数据 → 论文写作 → 投稿发表 |
| 综述论文 | 综述 / 调研类论文，没有实验 | 确定主题 → 检索筛选 → 精读归类 → 撰写综述 → 投稿发表 |
| 方法论文 | 提出新方法 / 算法 | 问题与灵感 → 文献调研 → 方法设计 → 实验与数据 → 论文写作 → 投稿发表 |
| 研究方向 | 长期方向 / 课题，可挂多个下属项目 | 入门调研 → 系统梳理 → 形成选题 → 持续跟踪 |
| 研读他人工作 | 精读、复现某篇论文 / 某个团队 / 开源项目 | 收集资料 → 精读理解 → 复现验证 → 总结汇报 |
| 基金 / 申报 | 基金、开题、中期报告等 | 选题论证 → 材料准备 → 撰写 → 修改定稿 → 提交答辩 |
| 资料库 | 只存文件，没有流程（课程资料、数据集、别人分享的材料） | 无 |

- 首页看板按类型分块显示，每块的列是该类型自己的流程；顶部可只看某一种类型。矩阵视图同理
- 「项目」页可按类型筛选
- 论文、研读等项目可以设置「所属研究方向」：在研究方向的详情页能看到全部下属项目，并可一键在该方向下新建论文项目
- 改类型：右键项目 →「类型 → …」，或在详情页点类型标签。原来的阶段不属于新流程时，会自动设为新流程的第一步
- 旧项目没有写类型，一律视为「论文」

## ✨ v0.6 新功能
### 文件预览
- 文件列表默认只显示最近 15 个，「再显示 30 个」按需展开；项目详情页每个分类只显示 4 个
- **单击文件 = 预览，双击 = 打开**；预览窗口里 ←/→ 键切换上一个 / 下一个
- 可预览：PDF、图片、音视频、Word（正文）、PPT（缩略图 + 每页文字）、Excel（各工作表前 200 行）、CSV / TXT / 代码、Markdown 笔记
- 笔记卡片右上角的 👁 按钮可预览笔记内容

### AI 提示词库（「AI 助手」页）
- 「新建提示词」保存常问 AI 的话，可加标签、置顶，按使用次数排序
- 内容里写 `{{变量}}`（如 `{{段落}}`、`{{项目}}`），复制时会弹窗填写；`{{项目}}` 提供项目下拉，`{{今天}}` 自动填日期
- 工作台内置指令可「存到我的提示词」后再改

### 首页时间维度
- **科研活跃度热力图**：近一年每天新建 / 修改的笔记和文件数，点某一天看当天明细
- **日历**：截止日、待办、会议、笔记按天显示，点日期看当天安排
- **项目时间轴**：每个项目从开始到截止日的进度条，虚线是「今天」，斜纹是今天之后的计划
- **每月新增笔记**：近 12 个月按类型堆叠的柱状图
- 每个模块标题可点击折叠

### 灵感页常用链接
- 顶部输入关键词，点 Google Scholar / arXiv / IEEE 等按钮直接在该网站搜索
- 「管理链接」可增删改、排序；网址里写 `{q}` 表示关键词位置，不写就直接打开该网址

### 计划页日历与时间
- 月视图 / 周视图切换；周视图按小时排列，红线是当前时间，双击时间格即可在该时段添加待办
- 「添加待办」可选日期、时间、所属项目：写进项目主页的「待办」小节，不选项目则写进 `科研/计划.md`
- 待办格式：`- [ ] 内容 📅 2026-10-08 ⏰ 14:30`，手写的也会自动出现在日历上

## 🕒 科研日志（v0.7，首页）
- 做完一件和科研有关的事（发邮件给导师、学习基础知识、读论文…），在首页「科研日志」写一句话，点「记录」或按 Ctrl+Enter，自动记下当前时间
- 可选快捷标签（#邮件 #学习 #阅读…，在设置里改）、关联项目；时间框留空 = 现在，也可以补记之前的时间
- 记录按天、按时间以时间线展示；鼠标移到某条上可修改或删除；「查看更早」往前翻
- 数据保存在 `科研/日志/YYYY-MM.md`（每月一个文件），格式 `- 14:30 做了什么 #标签 [[项目]]`，手写也能识别
- 命令面板「记录科研日志」可在任何地方快速记录

## 🌐 链接在 Obsidian 里打开
网页链接（灵感页按钮、文献 URL / DOI 等）默认用 Obsidian 内置「网页浏览器」打开（需在 设置 → 核心插件 开启「网页浏览器」）；zotero:// 链接仍交给 Zotero。可在工作台设置里改回系统浏览器。

## 🖥 首页一屏仪表盘（v0.8）
首页不再需要往下翻，所有内容在一屏内分成五块，每块内容多了在块内滚动：
- 左：**科研日志**（记录 + 时间线；「存为灵感」可把一句话直接存进灵感池）
- 中上：**流程看板**（多种项目类型时用右上角下拉切换；看板 / 矩阵切换）
- 中下：**图表**，三选一：项目时间轴 / 科研活跃度 / 每月新增
- 右上：**日历**（点「去计划页」看月 / 周视图）
- 右下：**即将截止 / 最近更新**（标签切换）
- 顶部一行统计：进行中项目、本周新增笔记、待办、30 天内截止（可点击跳转）
窗口较窄时自动变成两列，可以滚动查看。

## 🎨 背景配色（v0.9）
- 顶栏「主题」按钮（在 设置 / 更多 旁边）打开配色面板，点一下立即生效，只影响工作台页面，不改 Obsidian 本身。
- 10 套预设：跟随 Obsidian、墨夜蓝、森林绿、暗夜紫、咖啡棕、纯黑（深色）；暖纸米、雾霾蓝、薄荷绿、樱花粉（浅色）。
- 自定义：选一个背景色和强调色，卡片、边框、文字颜色会按背景深浅自动搭配。
- 「分区着色」开关：首页五个区块各带一种淡色（日志绿、看板蓝、图表紫、日历橙、列表粉），一眼分清区域。

## 📱 手机 / 平板（v0.10）
- 插件同时支持电脑端和 Obsidian 手机端。只要库（包括 .obsidian/plugins/research-workbench 文件夹）同步到手机，并在手机上开启这个插件就能用。
- 宽度不到 700px 时（手机，或电脑上把工作台拖得很窄）自动切到紧凑布局：
  - 顶栏按钮只显示图标，标签栏改成一行左右滑动；
  - 首页五块竖着排，顺序是 日志 → 即将截止 → 日历 → 看板 → 图表；
  - 看板每列约占屏幕 80% 宽，左右滑动；表格只留标题、状态等关键列。
- 手机上不能拖动卡片，**长按卡片 = 右键菜单**，可以改阶段、改状态、改归属、删除。
- **文献阅读（手机）**：打开时先显示 PDF（适合屏幕宽度）；右上角「AI」按钮在 PDF 和 AI 问答之间切换；在 PDF 里选字点「问 AI」会自动切到问答。工具栏精简为页码、缩放、译文开关、译文样式。滑远的页面会自动释放，长 PDF 也不卡。
- **我的文献（手机）**：表格自动变成一篇一张卡片，每列一段，生成 / 证据 / 编辑都一样。
- **译文标注（手机）**：手指按住译文拖动即可移位置，轻点打开样式面板（全宽显示）。
- 手机上做不了的事：连接 Zotero（只能在电脑上导入，导入后的文献笔记手机上照常看）、打开存在电脑上的库外链接文件、在文件夹中显示。
- 导入文件：点「选择文件导入」从手机里选文件，会按类型自动归档。

## 📁 项目文件夹（v0.11）
- 项目详情页右侧「项目文件夹」：像资源管理器一样浏览项目目录，自动识别你自己建的文件夹（含多级子文件夹），顶部路径可点击返回。右上角可切回「分类」视图（旧的按类型分组）。
- 「新建文件夹」建在当前所在位置；文件夹右键（手机长按）可以：导入文件到这里、新建子文件夹、重命名（笔记里的链接自动更新）、删除（进回收站）。
- 直接放在项目根目录的文件显示为「自由空间」。
- 整理文件：把文件行拖到某个文件夹（或顶部路径）上就是移动；也可以右键 →「移动到文件夹…」。「文件」页里的文件右键也有「移动到项目里的文件夹…」。
- 导入时可以选位置：导入弹窗里「放到项目里的哪个位置」——按类型自动归档（原来的方式）/ 项目自由空间 / 任意已有文件夹 / ＋新建文件夹。把文件从电脑拖到某个文件夹上，会自动预选这个文件夹。
- 带「自动」标记的文件夹（文献、汇报、数据、实验、写作、投稿、会议、代码…）是工作台按类型自动归档用的，也可以照常放东西。
- 「文件」总页仍按分类显示，不受文件夹影响。

## 📄 文献的 PDF（v0.12）
- 文献标题旁的 PDF 标记：**找得到 PDF 才显示**，并标明 PDF 在哪：
  - 绿色「PDF · 库内」：PDF 存在工作台库里，点击在 Obsidian 中打开；
  - 红色「PDF · Zotero」：PDF 在 Zotero 里，点击跳到 Zotero 打开；
  - 灰色「PDF · 电脑 / 网络」：库外的电脑路径或在线链接。
  - 两种都有时两个标记都显示；点标题打开 PDF 时优先用库内的。文献页筛选栏右侧有图例。
- 识别顺序：`pdf` 属性（库内链接必须真的存在，失效链接不显示）→ 和笔记同名、在同一文件夹的 PDF → 正文里链接/嵌入的第一个 PDF。
- 文献页右上角「点标题打开：笔记 | PDF」切换点标题本身打开什么（设置里也有）。选 PDF 时，没有 PDF 的文献仍打开笔记。
- 文献右键 →「关联 PDF…」：从库里挑一个 PDF（同项目、标题相近的排前面），或直接从电脑导入一个 PDF 并关联；已有的可以「更换」或「取消关联」。

## 🌐 划词翻译 + 📖 文献阅读面板（v0.13）
- **划词翻译**：在 Obsidian 里打开文献 PDF，选中一段文字就弹出翻译小窗（跨行的断词会自动拼好）。小窗里可以：
  - 切换翻译服务：Google / 微软（免费，无需密钥）、DeepL、百度、AI 大模型（DeepSeek、Kimi、通义等 OpenAI 兼容接口）；
  - 复制译文；点「❝」把原文 + 译文 + 页码链接写进这篇文献笔记的「## 划线摘录」（PDF 还没有笔记会自动建一个）；
  - 📌 固定小窗（点别处不关），Esc 关闭。
- 设置 → 科研工作台 →「划词翻译与文献阅读」：选中后直接翻译 / 先出「译」按钮 / 关闭；只在 PDF 里或笔记里也能划词；目标语言；各服务的密钥；有「测试」按钮。
- 命令：「翻译选中的文字」（可绑快捷键）、「开 / 关 划词自动翻译」、「打开文献阅读面板」。
- **文献阅读面板**（右侧栏，左侧功能区图标或文献页「阅读面板」按钮打开；打开有笔记的文献 PDF 时自动出现）：跟随当前打开的 PDF / 文献笔记，显示标题、作者、项目、阅读状态（可直接改）、PDF 来源，按钮直达笔记 / PDF / Zotero / DOI；三个分页：
  - 翻译：手动输入翻译 + 这篇文献的翻译记录（可复制、写入摘录、跳到对应页）；
  - 摘录：笔记里「划线摘录」的内容，点页码跳回 PDF 那一页；
  - 信息：摘要（可一键翻译）、期刊、DOI、引用键、标签。

## 📚 文献：我的文献 · 文献资料库 · 笔记摘录 · 文献阅读（v0.15）
PaperGrid 的四块功能直接做在工作台里，**不需要 Companion**；AI 全部走 设置 → 科研工作台 →「AI 接口」（DeepSeek / Kimi / 通义等 OpenAI 兼容接口）。

**文献页顶部三种模式**
- **我的文献（表格）**：每篇文献一行，AI 读全文填每一列（默认 研究目的 / 研究方法 / 主要结论）。
  - 格子里点「生成」，或勾选几篇点「分析选中的 N 篇」（不勾 = 分析全部空白格），同时跑 2 个。
  - 每格带「N 条证据」（原文摘句 + 页码，点页码跳到 PDF 那一页）；可复制、编辑、重新生成。
  - 「添加列」：一键加预设维度（研究背景、创新点、阵列与信号模型、对比方法、可复现性…）或自定义列名 + 要求；列菜单可左右移、整列分析、删除。
  - 「导出」生成 `科研/文献分析表.md`。结果存在插件目录 `papergrid-cells.json`。
- **文献资料库**：原来的看板 / 列表（按阅读状态）+ 文献原文文件。
- **笔记摘录**：所有文献「## 划线摘录」里的内容汇总，按文献分组；按标签筛选（原文高亮 / 划线翻译 / AI 解释 / AI 回答 / 手动 / 自定义），可搜索、改标签、写「我的笔记」、定位原文、问 AI、删除；「手动记一条」。

**文献阅读视图**（点文献标题或「PDF · 库内」打开；中间 PDF，右侧 AI）
- PDF 用工作台自己渲染：翻页、跳页、缩放（适合宽度 / 手动）、显示 / 隐藏原文上的译文；右侧 AI 可拖宽、可收起。
- PDF 里选中文字：翻译小窗 + 标在原文上 / 解释 / 总结 / **问 AI**（原文带页码引用到右侧问答）/ 摘录。
- **右侧 AI 问答树（Canvas Mindflow 的形式）**：
  - 基于整篇论文全文提问，回答流式出现（Markdown、公式、表格）；有「速读全文 / 方法细节 / 实验设置 / 局限与可做」快捷问题。
  - 在回答里**划选一段 → 追问**（可选预设问题，留空 = 详细解释）：追问长成子窗口，以卡片列在下面；原文里被划线的部分变黄，点它跳到对应卡片。
  - 点卡片标题进入这个追问，它就变成主窗口，可以继续提问、继续划线追问，无限往下；左上 ‹ 返回上一层，标题上方显示来路。
  - 「问答树」页显示整段探索的层级（1 → 1.1 → 1.1.1），点任一项跳转；可把整棵树写进文献笔记。
  - 每条回答：复制、重新回答、存入笔记摘录、删除这一轮。对话按文献保存在插件目录 `mindflow/`。
- 设置里可改：点文献标题 / 点「PDF · 库内」时用哪个阅读器、AI 读论文的长度、划线追问的预设问题。

**Remarkble 标注位置控制**
- PDF 上的译文**可以直接拖动**到想要的位置（按页面比例保存，缩放后仍在原处）。
- **译文样式面板**：阅读视图工具栏的「Aa」，或单击某条译文打开。滑块拖动时实时生效：
  - 字号（原文行高的百分比）、**与原文的距离**（单位是行高：0 = 紧贴，1 = 隔一行，负数 = 压到原文上）、原文上方 / 下方、颜色。
  - 默认改「全部译文」：所有译文一起变，也作为以后新译文的样式；切到「只改这一条」就只改点开的那条。
  - 「恢复默认样式」/「这一条恢复默认」；单击译文时还有「复制 / 摘录 / 删除」。右键译文直接出菜单。
- 设置里同样有位置、距离、字号滑块和颜色；「全部改回统一样式」会清掉以前单独调过的译文（拖动过的位置不变）。

# 科研工作台 · AI 协作约定

本仓库用「科研工作台」插件管理多个科研项目。AI 助手（Claude Code / Codex 等）在本仓库中工作时，请遵守以下约定，生成的文件会自动出现在工作台里。

## 目录结构
- `科研/项目/<项目名>/<项目名>.md`：项目主页（type: project）
- `科研/项目/<项目名>/灵感|文献|实验|数据|写作|投稿|会议/`：该项目的各类笔记
- `科研/灵感|文献|会议/...`：暂不属于任何项目的笔记
- 实验原始数据（csv / xlsx / 图片等）放在 `科研/项目/<项目名>/数据/`

## 项目主页 frontmatter
```yaml
type: project
kind: 论文 | 研究方向 | 研读他人工作 | 基金 / 申报 | 资料库   # 不写则视为「论文」
stage: 见下表（取决于 kind；资料库留空）
parent: "[[研究方向项目名]]"   # 可选：所属研究方向
status: 进行中 | 卡住 | 暂停 | 已完成
priority: 高 | 中 | 低
deadline: YYYY-MM-DD
next: "下一步要做的事"
description: "一句话描述"
```

| kind | 用途 | stage 可选值（按顺序） |
|---|---|---|
| 论文 | 写一篇论文 | 灵感 → 文献综述 → 实验 → 数据分析 → 论文写作 → 投稿发表 |
| 研究方向 | 长期方向 / 课题，可挂多个下属项目 | 入门调研 → 系统梳理 → 形成选题 → 持续跟踪 |
| 研读他人工作 | 精读 / 复现某篇论文、某个团队的工作 | 收集资料 → 精读理解 → 复现验证 → 总结汇报 |
| 基金 / 申报 | 基金、开题、中期等申报材料 | 选题论证 → 材料准备 → 撰写 → 修改定稿 → 提交答辩 |
| 资料库 | 只存文件，没有流程 | （留空） |

## 笔记 frontmatter
每条笔记必须有 `type`、`project`、`status`、`date`：

```yaml
type: idea | literature | experiment | data | draft | submission | meeting
project: "[[项目名]]"   # 不属于项目时留空
status: 见下表
date: YYYY-MM-DD
```

| type | 含义 | status 可选值 | 额外字段 |

| experiment | 实验记录 | 计划中 / 进行中 / 已完成 / 需重做 | conditions |
| data | 数据分析 | 待分析 / 分析中 / 已出图 / 已归档 | source |
| draft | 论文草稿 | 大纲 / 初稿 / 修改中 / 定稿 | section, target |

| 文献 | 文献/ | pdf, caj, epub |

| 实验数据 | 数据/ | csv, xlsx, mat, h5, txt, opj, tif |
| 会议资料 | 会议/ | m4a, mp3, wav, mp4 |
| 文稿 | 写作/ | docx, tex, bib |
| 图片 | 图片/ | png, jpg, svg |
| 代码 | 代码/ | py, ipynb, m, r, zip |
| 其他 | 附件/ | 其他格式 |

体积太大、只在库外保存的文件，用一条 `type: resource` 的“链接笔记”记录：
```yaml
type: resource
project: "[[项目名]]"
category: data        # 上表的分类 key：literature / slides / data / meeting / writing / image / code / other
path: "D:\\实验数据\\xxx.h5"   # 文件的绝对路径
size: 123456789
```

## Zotero
从 Zotero 导入的文献笔记带有：`zotero_key`（条目 key）、`zotero: "zotero://select/library/items/KEY"`、`pdf: "zotero://open-pdf/library/items/附件KEY"`。
笔记中 `<!-- zotero-annotations:start -->` 与 `<!-- zotero-annotations:end -->` 之间是从 Zotero 同步来的批注，会被工作台覆盖更新，请不要在这两行之间手写内容。

## 写作规则
- 文件名：会议、实验笔记以日期开头，如 `2026-10-05 组会.md`
- 待办统一写成 `- [ ] 任务内容 📅 YYYY-MM-DD`，工作台「计划」页会自动汇总
- 引用其他笔记用 `[[笔记名]]` 双链
- 推进项目阶段时，修改项目主页的 `stage` 和 `next`，并在「进展日志」追加一行
- 不要删除或重命名用户已有文件，除非用户明确要求

- **v0.21.9 问答里加图片**：读文献 / HTML 的 AI 问答输入框可以直接 **粘贴截图**（Ctrl/Cmd+V），也可以点输入框左边的图片按钮选文件，或把图片拖进输入框。图片会先显示在输入框上方（可点 ✕ 去掉），发送时和问题一起发给 AI；图片存在 `工作台数据/AI问答图片/年-月/`，超大的会自动缩小。只发图不写字也可以。每次最多带最近 6 张图。设置里新增「识图模型」：带图提问时改用这个模型（同一接口和密钥），留空就用原来的模型——如果原模型不支持图片会报错，填一个支持图片的模型即可（如 qwen-vl-max、gpt-4o）。
- **v0.21.10 Mindflow 标签页显示划线原文**：Mindflow 的问答树、右侧追问卡片、顶部标题和路径，划线追问的都显示你划的那段原文（黄色底），下面小字是当时问的话（用默认追问语时不显示）；在同一窗口里接着问的显示「↳ 问题」。这些地方和追问卡片的回答摘要、左侧历史列表里的 $公式$ 都会渲染显示。
- **v0.21.11 批量删除文献**：在「我的文献」表格里勾选文献后，工具栏会出现红色的「删除（N）」按钮。点了会列出要删的文献让你确认，可以选「只删文献笔记」（PDF 和全文转换结果保留），或「笔记 + 库里的 PDF + 全文转换结果（Markdown / 译文 / HTML）一起删」。还没有笔记的 PDF，删的就是 PDF 本身。别的文献也在用的 PDF 不会删，Zotero 里的 PDF 不受影响。删掉的东西都进回收站，可以找回。
- **v0.21.12 手机上 Mindflow 选字**：拖动选区的时候底部的「追问 / 笔记 / 复制」工具栏不再弹出来；手指抬起、选区停住约半秒后才出现。选好后再调整选区，工具栏会先收起，停住后再出来。

## 🧩 v0.22：自定义流程 · 文献分类与附件 · 实验与数据 · 会议材料 · 待办窗口
- **项目类型和流程可以自己定义**：设置 → 科研工作台 →「项目类型与流程 · 管理…」，或首页看板每种类型标题右边的 ⚙，或新建项目窗口里的「管理项目类型和流程」。
  - 可以新建类型、改名、改颜色、改说明、上下排序、删除；每种类型的阶段可以增删、改名、排序，并选它主要产出哪类笔记（灵感 / 文献 / 实验与数据 / 写作 / 投稿 / 会议，用于矩阵统计和点击跳转）。
  - 阶段全部删掉 = 没有进度（像资料库那样只存文件）。
  - 默认新增了「综述论文」和「方法论文」两种类型。改类型名、改阶段名时，已有项目的 kind / stage 属性会一起改；删掉的类型，用它的项目变成「论文」。
- **单个项目单独设流程**：项目右键 →「编辑这个项目的流程…」，或项目详情页的「编辑流程」标签。三选一：用类型的流程 / 这个项目单独设流程 / 没有流程。新建项目时也能直接填「自定义流程」（用 → 或逗号分隔，填「无」= 没有进度）。写在项目主页的 `stages` 属性里。首页看板里，单独设了流程的项目会按自己的流程另起一块。
- **实验和数据合并**：顶部「实验」「数据」两个标签合成「实验与数据」一页，实验记录和数据分析笔记放在一起（看板列：计划中 / 进行中 / 分析中 / 已完成 / 需重做，数据笔记的旧状态自动对应）。论文默认流程里的「实验」「数据分析」两步合成「实验与数据」，旧项目自动对应。实验记录也可以挂数据文件当附件。
- **文献「我的分类」**：文献页第二排是自己建的分类。点「＋」新建，用「父/子」可以建子分类；一篇文献可以在多个分类里。
  - 加入分类：在「我的文献」表格勾选后点工具栏「分类」；或右键文献 →「加入 / 移出分类」；或把文献卡片拖到分类按钮上。
  - 分类按钮右键可以建子分类、改名、删除（只是移出分类，不删文献）。点分类只看这一类，还有「未分类」。表格里文献下面会显示它的分类小标签。
  - 分类写在文献笔记的 `collections` 属性里；还没有笔记的 PDF 先记在插件里，建笔记时自动搬过去。
- **文献附件（像 Zotero）**：一篇文献下面可以挂 PPT、讲稿、自己的理解笔记、录音、数据等。
  - 在表格里文献标题下的 📎 小标签（没有附件时鼠标移上去才显示「附件」）点开，或右键 →「附件…」，或文献阅读视图工具栏的 📎。
  - 附件窗口里可以从电脑选文件 / 拖进来（复制到「<笔记所在文件夹>/附件/<笔记名>/」），或从库里搜已有文件加入（默认只关联、文件留在原处；勾选「移进附件文件夹」就搬过去）。每个附件可以打开、移进附件文件夹、取消关联、删除（进回收站）。
  - 记在笔记的 `attachments` 属性里（[[链接]]，改名 / 移动会自动更新）；附件文件夹里的文件自动算附件。任何笔记（实验记录、会议纪要…）都能用。
- **新建会议纪要**：点「新建会议纪要」会打开一个窗口，一次填好标题、日期和时间、所属项目、参会人、**简介**，以及**材料**（录音、视频、PPT、PDF、图片，可以从电脑选、拖进来、手机上直接录音，或从库里找已有文件）。材料会放进这次纪要的附件文件夹，录音 / 视频 / 图片直接嵌在纪要开头的「📎 材料」里，可以当场播放。会议列表里会显示简介和材料数。
- **待办窗口**：计划页、项目详情页、日历里点一条待办，会弹出窗口，可以改内容、日期、时间、写备注（写在待办下面的缩进行）、标记完成、删除，保存后写回原笔记，不用再跳到 md 文件里改。窗口底部「来自：…」可以跳到原笔记。
- **v0.22.1 项目详情页左栏显示全部内容**：除了按类型的笔记（文献、实验与数据、写作、投稿、会议…），还会列出没写类型的 md 笔记（「其他笔记」，旁边的 🏷 按钮可以一键设成某类笔记）和项目里的各类文件：文献原文（PDF 等）、PPT 汇报、实验数据、文稿、图片、代码、会议资料、其他文件（HTML 等）。每组先显示最近 6 个，点「全部 →」展开。单击文件预览，双击打开，右键有更多操作。右栏仍是按文件夹看的「项目文件夹」。
- **v0.22.2 跨项目移动**：文件、笔记、文件夹右键的「移动到文件夹…（可跨项目）」打开的窗口顶部可以选目标项目，再选那个项目里的文件夹（或新建文件夹）。跨项目移动的笔记，`project` 属性会自动改成新项目；移动整个文件夹时，里面属于原项目的笔记也一起改。笔记右键菜单也加了这一项。

- **顶部切换**：工作台左上角多了「科研 ｜ 生活」开关。两个面板各自记住上次停在哪个标签。命令面板里也有「打开生活面板」「打开科研面板」。

  - 生活面板：生活主页、知识库、生活记录、Mindflow。
- **生活主页**就是原来的 Daily Hub（已整合进工作台，不用再单独装）：日记热力日历、连续记录天数、今天的上午 / 下午 / 晚上快速记录、各类别按钮（健身、饮食、记账、想法…）、按天看所有记录、写给自己 / 待办 / 常用链接，以及「AI 整理到项目」。

  - 只看 `生活/` 里的日期笔记，科研那边的日期笔记（旧科研日志、会议纪要）不会出现在生活日历里。
  - 「AI 整理到项目」默认用工作台的 AI 接口；日记里科研相关的内容（读文献、实验、写论文、组会…）会写进科研面板的「科研日志」（带 #日记整理 标签），生活类的才放进生活类别。设置 → 科研工作台 →「生活面板（Daily Hub）」里可以关掉。

- **知识库**：两个面板都有「知识库」标签，按文件夹浏览 `知识库/`（技术笔记、基础学科、读书笔记…），可以新建文件夹、导入、拖动整理。设置里可以改文件夹。文件「移动到文件夹」的窗口里也能选「知识库」「生活」。
- **从另一个库导入**：设置 → 科研工作台 →「从另一个库导入」，或命令「从另一个库导入（合并自学集等）」。只能在电脑上用。
  - 识别出是「自学集」时用对应的规则：日期记录 → 生活/日记；项目里的生活类别 → 生活/记录；科研日志、会议记录、论文进展、CA1 计划、旁听、英语论文 → 科研里对应的项目或文件夹；旧科研日志 → 科研/日志/历史；计划、线下实验、综述材料 → 对应项目；02_记录与成果、03_工具与模板 → 知识库；其他 → 归档/自学集。插件数据（_QClaw、copilot 等）默认不导入。
