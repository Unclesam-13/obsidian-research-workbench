# 🧪 科研工作台 Research Workbench

> 一个 Obsidian 插件：把**多个科研项目 × 完整科研流程**放进一个工作台。从灵感、读文献、做实验到写论文、投稿，每个项目走到哪一步一眼看清；读论文时划线就能问 AI，问答自动长成一棵树，好的回答一键存进笔记。

桌面端（Windows / macOS / Linux）和手机 / 平板都能用。所有数据都是库里的普通 Markdown 文件，不依赖任何服务器。

---

## 为什么做这个

读博时同时推进好几个课题，资料散落在 Zotero、PDF 文件夹、笔记、聊天记录里，很难回答「这个项目现在卡在哪」「这篇论文我上次问 AI 问到哪了」。科研工作台把这些串在 Obsidian 里：

- **项目 × 阶段**：每个项目都走 **灵感 → 文献综述 → 实验 → 数据分析 → 论文写作 → 投稿发表**。
- **读文献 + AI**：PDF 和 HTML 旁边就是 AI 问答，划线追问、公式渲染、截图提问，回答能直接变成笔记摘录。
- **自动留痕**：手写的科研日志，加上自动记下每次新建、导入、移动、编辑的全局记录。

## 功能一览

### 🏠 首页与项目
- **看板**：每列一个阶段，拖动项目卡片即可推进阶段，并自动写入项目主页的进展日志。
- **矩阵**：项目 × 阶段的笔记数量，点格子直达对应内容。
- **一屏仪表盘**：今日 / 本周时间维度、截止日期、待办、科研日志、全局记录。
- **项目详情页**：项目主页属性（阶段、状态、下一步、截止日期）、项目文件夹、各类笔记。
- **拖入导入**：把 PDF、PPT、Excel、实验数据、录音、代码等拖进工作台，按类型自动归类到项目。
- **重命名项目**：主页、文件夹和所有 `[[链接]]` 会一起更新。

### 📚 文献
- **我的文献**表格：标题、作者、年份、期刊自动识别（PDF 元数据 + 首页排版，可选 AI 校对）；每列可用 AI 批量生成（研究问题、方法、结论…）。
- **分类筛选**：有笔记 / 还没笔记 / 已转 Markdown / 有译文 / 有 HTML / 有讲解稿 / 没有 PDF；再加上自己建的「我的分类」（可多选、可嵌套）。
- **文献附件**：像 Zotero 一样，每篇文献下面挂 PPT、讲稿、理解笔记、录音、数据。
- 没建笔记的 PDF 也会列出来，一键建笔记。
- **Zotero 联动**：导入条目和高亮注释，跳回 Zotero 打开 PDF。
- **笔记摘录**：所有划线摘录和 AI 回答摘录集中浏览，公式照常渲染。

### 📖 文献阅读视图
- PDF **划词翻译**（多种机器翻译或 AI），译文可标注在 PDF 上。
- **自定义划词按钮**：解释、AI 释译、总结、问 AI…，可设置成直接发问、引用后自己问，或在小窗里回答。
- 右侧 **AI 问答树**：
  - 在回答里划线就能追问，形成分层的问答树；树里显示的是你划的那段原文，而不只是提示词。
  - 公式可选中、可渲染；追问过的原文会持续高亮。
  - 可以**粘贴截图、拖入或选择图片**提问，并可单独设置识图模型。
  - 点树上任一节点，跳到对应的那一问。
  - 好的回答一键「存入笔记摘录」。

### 📄 PDF 全文
- **PDF → Markdown**：本地提取（免费），或 MinerU / Mistral OCR（公式、表格、图片都能还原）。
- **一键全文翻译**：AI 或机器翻译，逐段对照，公式和引用原样保留。
- **HTML 阅读页**：单文件、离线 KaTeX 公式，可切换中 / 英 / 中英对照，带目录，手机也好读。
- 在 Obsidian 里直接打开 `.html`，旁边同样有 AI 问答。

### 🧠 Mindflow
- 内置的划线追问式 AI 对话：问答树、历史、收藏夹、想法笔记，还能一键生成 Canvas 总览图（移植自 [canvas-mindflow](https://github.com/Unclesam-13/canvas-mindflow)）。

### 🌿 生活面板
- 顶部「科研 ｜ 生活」一键切换，两边的日历、待办、操作记录分开。
- 生活主页（整合自 [Daily Hub](https://github.com/Unclesam-13/obsidian-daily-hub)）：日记热力日历、上午 / 下午 / 晚上快速记录、健身 / 饮食 / 记账等类别、按天查看、AI 把日记拆到各类别（科研相关的写进科研日志）。
- 知识库：按文件夹浏览长期积累的笔记。
- 从另一个 Obsidian 库导入：按规则复制、自动改链接，原库不动。

### 🗂 其他
- 灵感 / 实验 / 数据 / 写作 / 投稿 / 会议笔记的看板和表格。
- **计划**：汇总所有 `- [ ]` 待办和截止日期，可以在日历中查看；点待办弹出窗口修改内容、日期、备注、完成，自动写回原笔记。
- **AI 助手**：常用提示词库，一键复制。
- **全局记录**：自动记录文件操作，可按时间、类别、项目筛选。
- 背景配色、深浅色主题，适配手机悬浮导航栏。

## 安装

目前还没有上架社区插件市场，可以手动安装：

1. 在本页点 **Code → Download ZIP**，解压后取出 `main.js`、`manifest.json`、`styles.css`、`vendor-katex.js`、`vendor-katex.css` 五个文件（有 [Releases](https://github.com/Unclesam-13/obsidian-research-workbench/releases) 时也可以直接在那里下载）。
2. 在库里新建文件夹 `.obsidian/plugins/research-workbench/`，把这五个文件放进去。
3. 打开 Obsidian → 设置 → 第三方插件，关闭安全模式，然后启用「科研工作台」。
4. 点左侧边栏的 🧪 图标，或在命令面板搜索「打开科研工作台」。

也可以用 [BRAT](https://github.com/TfTHacker/obsidian42-brat) 插件，填入 `Unclesam-13/obsidian-research-workbench` 安装，之后能自动更新。

第一次打开时会在 `科研/` 下生成几个「示例-」项目，熟悉后直接删除即可。

## 配置 AI

在 设置 → 科研工作台 → AI 里填写接口地址、密钥和模型。接口需要兼容 OpenAI 格式，DeepSeek、Kimi、通义千问、智谱、硅基流动、OpenRouter、OpenAI 都可以。

- DeepSeek 的深度思考会自动处理：思考过程可折叠；思考把输出额度用完时，会关掉思考自动重答。
- 带图片提问时，可另外指定一个「识图模型」。
- PDF 转换（MinerU / Mistral）和机器翻译（DeepL、百度、微软…）的密钥都是可选的。

## 数据与隐私

- 项目、笔记靠 frontmatter 里的 `type` / `project` 识别。手写的笔记只要属性填对，也会出现在工作台里。
- 工作台自己的数据（问答树、译文标注、全局记录、全文转换结果）都存在 `科研/工作台数据/` 下的普通文件里，随库一起同步。
- **API 密钥只保存在本地的插件设置（`data.json`）里**。插件只会把你主动发起的请求发给你自己配置的服务，不收集任何数据。

完整的使用说明和数据格式约定见 [docs/使用说明.md](docs/使用说明.md)。
